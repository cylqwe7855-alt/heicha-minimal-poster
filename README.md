# 喜茶式极简海报提示词 Skill

这是一个用于生成 `image2` 图生图提示词的中文 Skill。它可以读取用户上传的主体图片，也可以理解用户提供的文字主体，输出一段可直接复制使用的极简治愈系白底创意海报提示词。

本项目是私有仓库，仅供获得 GitHub 访问权限的账号使用；它不是喜茶官方工具，也不包含喜茶 Logo、品牌素材或官方提示词。

## 能力

- 从上传图片中锁定单一真实主体，保留轮廓、比例、材质、纹理和识别特征，并干净抠出原背景。
- 生成居中偏下、顶部留白充足的白底高级静物摄影构图。
- 根据主体的材质、功能、形态或状态，设计 4–5 个纯黑手绘线稿小人的有逻辑互动动作。
- 自动生成 1 句 6–12 字、温柔克制且呼应主体的中文手写短文案。
- 将光影、摄影质感、整体风格和负面约束整合为一段完整提示词，减少模型跑偏和 AI 瑕疵。
- 只有文字时，也能把文字解析为单一主体并生成提示词；主体不明确时会先要求补充。

## 安装

先确认当前 GitHub 账号对私有仓库有访问权限，然后执行：

```bash
npx skills add cylqwe7855-alt/heicha-minimal-poster -g -a codex -y
```

也可以手动克隆后，将 `heicha-minimal-poster` 文件夹放入对应的 Skill 目录：

```bash
git clone https://github.com/cylqwe7855-alt/heicha-minimal-poster.git
```

## 使用

安装后可以直接说：

> 使用我上传的甜品图片，做成极简治愈系白底海报，文案要和甜品的口感有关。

或者：

> 把“一只正在窗边晒太阳的橘猫”做成极简手绘互动海报提示词。

默认交付一段完整的 `image2` 提示词和一句素材使用说明。如果用户明确要求且当前平台提供图像生成能力，调用方可以在整理提示词后直接生成图片；否则交付提示词，不虚构生成结果。
